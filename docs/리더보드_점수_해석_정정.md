# 리더보드 점수 해석 정정 — "원인 불명 1.8억 차이"는 계산 착오

작성 2026-11-05. 대상: `EXPERIMENTS.md`의 "v1 점수 해석" 문단.

## 한 줄 요약

"기대 S 6.62B vs 실제 6.44B, 약 1.8억 차이"는 **매전수익 자리에 예측값으로 계산한 수익을 넣어서 생긴 착시**다.
실제 발전량 기준으로 다시 계산하면 리더보드 점수는 로컬 검증과 거의 맞는다. 평가 연도에 원인 모를 큰 오차가 있다는 가정은 버려도 된다.

## 무엇이 잘못됐나

평가식은 다음과 같다.

```
S = Σ SMP·실적  −  0.10·Σ SMP·k·|예측 − 실적|
    └ 매전수익 ┘    └────── 페널티 W ──────┘
```

매전수익은 **실적(실제 발전량)**으로 계산한다. 그런데 기존 해석은 이렇게 계산했다.

| 항목 | 기존 해석 |
|---|---|
| 매전수익 | Σ SMP·**예측** = 6.81B ← 여기가 잘못 |
| W | 로컬 W 213M × SMP 비율(108/122) ≈ 189M |
| 기대 S | 6.81B − 0.19B ≈ 6.62B |
| 실제 리더보드 | 6.44B → "1.8억 원인 불명" |

v1은 검증 연도에 예측이 실적보다 약 3% 많았다(과대예측). 그만큼 "예측 수익"이 "실제 수익"보다 커서 기대 S가 부풀려졌다.

## 다시 계산하면

리더보드 점수에서 실제 매전수익을 거꾸로 구한다. 로컬 검증의 `W / 매전수익` 비율이 평가 연도에도 비슷하다고 가정하면 `실제 매전수익 = 리더보드 S ÷ (1 − W/매전수익)`이다.

| | v1 | v2 |
|---|---|---|
| 리더보드 S | 6,439,103,503 | 6,438,654,673 |
| 로컬 W / 매전수익 (최적 구성) | 2.84% | 2.68% |
| **역산한 실제 매전수익** | **6.627B** | **6.616B** |
| 역산한 W | 약 188M | 약 177M |
| Σ SMP·예측 (제출 파일로 계산) | 6.806B | 6.598B |
| 예측 / 실적 | 1.027 (+2.7% 과대) | 0.997 |

- **실제 매전수익은 모델과 무관한 고정값**인데, 예측값이 다른 두 버전에서 각각 역산한 값이 **6.62B 근처로 0.2% 안에서 일치**한다. 로컬 검증이 리더보드를 잘 설명한다는 근거다.
- 다른 방법으로 계산해도 같다. 예측 수익 6.81B를 검증 연도 과대예측(+3.1%)으로 나누면 실제 수익은 약 6.60B, 여기서 W 0.19B를 빼면 S ≈ 6.42B다. 실제 6.44B와 0.3% 차이다.

## 주의할 점

- 평가 구간 실적은 공개되지 않아 **확정이 아니라 강하게 뒷받침되는 추정**이다. "W/매전수익 비율이 해마다 비슷하다"는 가정에 기댄다.
- 리더보드는 평가 구간 전체로 계산하므로 잡음이 없다. 버전 간 점수 차이는 그대로 W 차이다. 매전수익은 고정이라 상쇄된다.

## 아직 풀리지 않은 것 (진짜 질문)

1. **v2의 배율 보정(×0.975)이 리더보드에서 효과가 없었던 이유.** 역산상 v2는 총량 편향이 거의 사라졌는데(0.997) 점수는 v1과 같다. 2폴드 검증에서도 배율 0.975~0.98은 해마다 안정적으로 W를 1~2% 줄였다.
2. **로컬에서는 v1(site_id)이 v2보다 3~9% 나쁜데 리더보드에서는 v1이 약간 좋은 이유.** 가설은 이렇다. 검증 연도에는 편입 1년 미만 발전소가 많아 site_id가 불리하고, 평가 연도에는 253곳 모두 1년 이상 이력이 있어 site_id가 유리하다. 발전소별 과거 효율 피처로 확인할 예정이다.
