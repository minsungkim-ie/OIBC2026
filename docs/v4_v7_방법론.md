## 1. 2폴드 연 단위 검증 (`scripts/10~12_cv_*`)

| 폴드 | 학습 | 검증 |
|---|---|---|
| A | 2021-06 ~ 2023-05 | 2023-06 ~ 2024-05 |
| B | 2022-06 ~ 2024-05 | 2024-06 ~ 2025-05 (기존 v1·v2 검증 구간) |

- 평가 구간(1년)과 같은 모양을 두 해에 반복한다. 한 해에서만 좋은 설정을 거르기 위해서다.
- 배율처럼 숫자를 정하는 것은 **다른 해에서 정해 이 해에 적용**해 채점한다. 같은 해로 정하고 같은 해로 채점하면 점수가 부풀려진다.
- 지표는 대회 식 그대로의 W (참조 구성, 학습 구간 SMP·k).
- 학습 구간에는 모든 지점의 예보가 통째로 빠진 날(2022-05-08)이 있어 학습에서 뺐다 (`impute_forecast(allow_nan=True)`, 학습 구간 전용).
- 재현 확인: 폴드 B의 v2 방식 W 210.1M ≈ 기존 리포트 210.8M.

## 2. v4에서 바꾼 것

| 변경 | 2폴드 결과 | 이유 |
|---|---|---|
| **청천지수(csi) 타깃 모델 추가**, v2 모델과 평균 | csi 단독 W −1.75% / −1.07% | 설비이용률 대신 "맑은 날 기대치 대비 비율"을 맞히게 하면 계절·시간 효과가 빠지고 날씨 효과만 남는다. 청천 일사는 Haurwitz 공식(태양 천정각만 사용, 외부 데이터 없음). L1 손실이 같아지도록 가중치에 청천값을 곱한다 |
| **라운드 가중 17시 70%** (기존 반반) | v2 −0.2% / −0.7% | 17시 예보가 10시보다 정확하다 (운량 상관 0.79 vs 0.75) |
| **배율 α = 0.978** | 해마다 최적 α 0.976 / 0.980으로 안정. 교차 적용 시 W −1~2% | 발전소별 중앙값(L1) 예측의 합은 그룹 합계의 중앙값보다 크다 → 구조적 과대예측(+1~3%) |
| **구성 재최적화** (앙상블 잔차, 폴드 B) | 홀수주 최적화 → 짝수주 채점 −2.04% | 기존 지역탐색 그대로, 잔차만 새 앙상블 기준 |

시간대별 배율은 전체 배율 하나보다 나을 게 없어 넣지 않았다.

## 3. v7에서 바꾼 것 — 발전소 효율 피처

**정의** (`src/oibc/cv.py`의 `site_efficiency`): 학습 구간 마지막 1년, 각 발전소의 설비이용률을 **같은 시각 전 발전소 중앙값으로 나눈 비율**의 중앙값.

| 피처 | 시간대 | 담는 정보 |
|---|---|---|
| `eff_am` | 8~10시 | 동향 패널이면 크다 |
| `eff_mid` | 11~15시 | 전반적 효율 (노후·음영·인버터) |
| `eff_pm` | 16~18시 | 서향 패널이면 크다 |
| `eff_days` | — | 효율을 잰 날 수 (신뢰도) |

**왜**: v1(site_id)은 로컬에서 v2보다 3~9% 나빴는데 리더보드에선 비슷했다. 검증 연도엔 편입 1년 미만 발전소가 많지만(폴드 B 시작 시 이력 있는 곳 205/253), 평가 연도엔 253곳 모두 이력이 있다. 발전소별 특성이 평가 연도엔 도움이 된다는 가설 → site_id처럼 외우지 않고 숫자 4개로 요약했다.

**검증 함정**: 검증 연도의 신규 발전소(효율 피처 없음)에서 크게 과소예측해, 전체 기준으로는 W가 나빠 보였다(+11% / +0.5%). 평가 연도와 같은 조건(이력 있는 발전소만)으로 비교하면 개선:

| 앙상블 (α 0.978) | 폴드 A (106곳) | 폴드 B (205곳) |
|---|---|---|
| v4: v2 + csi | 51.65M | 164.00M |
| v2e + csie (2개) | 51.24M (−0.8%) | 162.97M (−0.6%) |
| **v7: v2 + csi + v2e + csie (4개)** | 51.35M (−0.6%) | 163.03M (−0.6%) |

평가 연도 최소 이력은 119일이라 위 함정에 해당하지 않는다. v7는 위험 분산을 위해 4개를 섞었고, 구성·α는 v4 그대로 둬 효과를 분리했다. 로컬에선 2개만 쓴 쪽이 근소하게 낫다 (다음 실험 후보).

## 4. 재현

```bash
python scripts/10_cv_build.py                 # 2폴드 피처 캐시 (약 2분)
python scripts/11_cv_train.py v2 csi v2e csie # 폴드×라운드별 학습 (약 1시간)
python scripts/12_cv_eval.py                  # outputs/v4/12_cv_report.md
python scripts/13_final.py v4 v2 csi          # submissions/v4 (구성 최적화 포함)
python scripts/13_final.py v7 v2 csi v2e csie --comp submissions/v4/composition.csv --alpha 0.9779
python scripts/04_check_submission.py submissions/v7
```

`v4`·`v7` 태그는 같은 커밋이다. 위 두 명령으로 각각 재현된다.
